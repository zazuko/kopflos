# @kopflos-cms/plugin-deploy-resources

Deploy RDF resource files and plugin-generated resources to a Kopflos application's default SPARQL store.

## AI skill

The package includes [kopflos-deploy-resources](skills/kopflos-deploy-resources/SKILL.md), an agent skill covering configuration, file-to-IRI mapping, named graphs, deployment policies, and watching. It is shipped in `node_modules/@kopflos-cms/plugin-deploy-resources/skills/kopflos-deploy-resources`; point your agent at its `SKILL.md` or copy the folder into your agent's skills directory.
