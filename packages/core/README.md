# @kopflos-cms/core

Kopflos defines RDF web APIs using resource shapes, targets, resource loaders, and handlers.

## AI skill

The package includes [kopflos-resources](skills/kopflos-resources/SKILL.md), an agent skill for defining resources and their HTTP behavior in RDF. It is shipped in `node_modules/@kopflos-cms/core/skills/kopflos-resources`; point your agent at its `SKILL.md` or copy the folder into your agent's skills directory.
