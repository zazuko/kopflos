03 / Interpretation

What these measurements support

Better scaling with route count

With 20 candidate routes, the new path is about 18–19× faster in these fixtures. With one route, the measured latency ranges overlap. Local evaluation also makes the page IRI usable before CONSTRUCT.

Budget for the runtime

Comunica adds about 30 MiB of retained Node heap here, and peak RSS rises too. Its first-use import and initialization cost is visible on small queries. Oxigraph’s deduplicated legacy graph also transfers fewer bytes than the new JSON bindings.

Methodology, scope, and reproducibility

Measurement design

Native Oxigraph 0.4.7 through an in-memory Python HTTP endpoint, in a separate process from the Node application. Three fresh application processes per implementation and workload; one warm-up and three timed requests per process. Variant order alternates. Every output’s quad count and sorted-term SHA-256 are checked against the expected graph.

Warmed bars show medians. Latency whiskers show observed p10–p90, not statistical confidence intervals. Each resource has the stated property count plus rdf:type and matches exactly one page.

Included and excluded

Includes rewriting, route compilation, HTTP query execution, parsing, URL resolution, and final dataset materialization. Excludes routing-graph loading, fixture construction, HTML rendering, explicit GC, and correctness hashing.

Localhost, no compression or artificial latency, one concurrent request. Memory samples belong to the application process. Shared-host synthetic results are not production latency estimates. Queries that join endpoint data using a resolved page IRI can have additional requests; those are not measured here.
